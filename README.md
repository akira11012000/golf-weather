# お天気キャディー

ゴルフ場ごとに、4つの天気予報を比べて「このゴルフ場で当たる予報」を選べる天気アプリです。

**アプリを開く**

| ゴルフ場 | URL |
|---|---|
| 総武カントリークラブ 北コース | https://akira11012000.github.io/golf-weather/#sobu |
| KOSHIGAYA GOLF CLUB（越谷ゴルフ倶楽部） | https://akira11012000.github.io/golf-weather/#koshigaya |

iPhoneでは、Safariで開いて共有ボタン →「ホーム画面に追加」を押すと、アプリのように使えます。

---

## 主な機能

- **4つの予報を比較**：気象庁・ヨーロッパ（ECMWF）・アメリカ（GFS）・ドイツ（ICON）の予報を、プレー時間に絞って1時間ごとに表示します。
- **ひと目で分かるまとめ**：「雨の心配は小さい」「雨具が必要」などの一言と、合計雨量・雨の時間・気温・最大風速を表示します。
- **予報の信頼度**：4つの予報がそろっていれば「高」、分かれていれば「低」と表示します。
- **総合予報**：このゴルフ場でよく当たっている予報ほど重みを大きくして、平均した予報を出します。
- **的中の記録**：毎日自動で、各予報（前日・2日前・3日前に出されたもの）とアメダスの実測を比べて記録します。期間別の的中率、雨の見逃し・空振り、気温の誤差、日別の記録を表示します。
- **雨雲の動き**：ゴルフ場の周り約100km四方の雨雲の予報を、今から24時間後まで地図で表示します。
- **2コースの切り替え**：総武カントリークラブ 北コースと、KOSHIGAYA GOLF CLUBを切り替えられます。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | アプリ本体 |
| `apple-touch-icon.png` | ホーム画面用のアイコン |
| `record.py` | 予報と実測を比べて記録するプログラム |
| `.github/workflows/record.yml` | `record.py` を毎日自動で実行する設定（GitHub Actions） |
| `data/records.json` | 的中の記録（自動で更新されます） |

## しくみ

1. アプリを開くと、ブラウザが Open-Meteo から最新の予報を取得します。
2. GitHub Actions が毎日（日本時間 1:30 ごろ）`record.py` を実行し、前日までの予報と、ゴルフ場に最も近いアメダスの実測を比べて `data/records.json` に追記します。
3. アプリはその記録を読み込んで、成績表を表示し、総合予報の重み付けに使います。

判定の条件：7〜17時の1時間ごとの値で比較します。予報は1時間0.3mm以上、実測は1時間0.5mm以上を「雨あり」とみなします。

- **予報データ**：[Open-Meteo](https://open-meteo.com/)（[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)）
  - 元データ：気象庁、ヨーロッパ中期予報センター（ECMWF）、アメリカ海洋大気庁（NOAA/NCEP）、ドイツ気象局（DWD）

- **地図**：[地理院タイル（国土地理院）](https://maps.gsi.go.jp/development/ichiran.html)
