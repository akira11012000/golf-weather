# お天気キャディー

ゴルフ場ごとに、4つの気象モデルの予報を比べて「このコースで当たる予報」を選べる天気アプリです。

**アプリを開く**：https://akira11012000.github.io/golf-weather/

- 総武カントリークラブ 北コース：https://akira11012000.github.io/golf-weather/#sobu
- KOSHIGAYA GOLF CLUB（越谷ゴルフ倶楽部）：https://akira11012000.github.io/golf-weather/#koshigaya

iPhoneはSafari、AndroidはChromeで開き、メニューから「ホーム画面に追加」を選ぶと、アプリのように使えます。

現在のバージョン：**1.4（2026-09-20）**

## 主な機能

- **4モデルの比較**：気象庁・EU（ECMWF）・US（GFS）・ドイツ（ICON）の予報を、プレー時間に絞って1時間ごとに表示します。
- **天気マーク**：1時間ごとに、快晴・晴れ・曇り・少雨・中雨・豪雨をマークで表示します。
- **風の警戒色**：風速5m/s以上は黄、7m/s以上はオレンジ、10m/s以上は赤で表示します。
- **ひと目で分かるまとめ**：「雨の心配は小さい」「雨具が必要」などの一言と、合計雨量・雨の時間・気温・最大風速。
- **予報の信頼度**：4モデルの予報がそろっていれば「高」、分かれていれば「低」。
- **総合予報**：このコースでよく当たっているモデルほど重く扱って平均します。
- **的中の記録**：毎日自動で、各モデルの予報（前日・2日前・3日前）とアメダスの実測を比較して記録します。期間別の的中率、雨の見逃し・空振り、気温の誤差、日別の記録を表示します。
- **雨雲の動き**：コース周辺 約100km四方の雨雲予報を、24時間先まで地図で表示します。
- **ゴルフ場の追加**：「＋ ゴルフ場を追加」から名前や住所で検索して追加できます。追加したコースはその端末にだけ保存され、毎日の自動記録の対象外です。
- **更新の自動確認**：新しい版が公開されると、画面下に「新しい版があります」と表示され、ボタン1つで切り替えられます。
- **プレー時間**：初期設定は5時〜15時。変更できます。

## しくみ

1. アプリを開くと、ブラウザが Open-Meteo から最新の予報を取得します。
2. GitHub Actions が毎日（日本時間1:30ごろ）`record.py` を実行し、前日までの予報と最寄りアメダスの実測を比べて `data/records.json` に追記します。
3. アプリがその記録を読み込み、成績表の表示と総合予報の重み付けに使います。

## 判定の条件

- 比較時間帯：7〜17時の1時間値。予報0.3mm以上、実測0.5mm以上を「雨」とみなします。
- 天気マーク：快晴＝雲量15%未満／晴れ＝85%未満／曇り＝85%以上／少雨＝1時間0.3mm以上／中雨＝3mm以上／豪雨＝10mm以上
- 重み ＝ 雨の的中率 ÷（0.5＋気温の誤差）＋ 1 ÷（0.3＋雨量の誤差）。合計が1になるよう調整します。
- 記録が10日分以上たまると、30日分の記録で重みを決めます。少ないときは直近8日分をその場で計算します。

※天気マークの区分は本アプリ独自の目安であり、気象庁が発表する天気予報の区分とは一致しません。

## データの出典

- **予報データ**：[Open-Meteo](https://open-meteo.com/)（[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)）
  - 元データ：気象庁、ヨーロッパ中期予報センター（ECMWF）、アメリカ海洋大気庁（NOAA/NCEP）、ドイツ気象局（DWD）
- **実測データ**：[気象庁 アメダス](https://www.jma.go.jp/bosai/amedas/)（出典：気象庁ホームページ）
- **ゴルフ場の検索**：[OpenStreetMap Nominatim](https://nominatim.openstreetmap.org/)（© OpenStreetMap contributors, ODbL）、[国土地理院 住所検索](https://msearch.gsi.go.jp/)
- **地図**：[地理院タイル（国土地理院）](https://maps.gsi.go.jp/development/ichiran.html)
- **地図表示**：[Leaflet](https://leafletjs.com/)（BSD 2-Clause License）
